# UI 与交互优化交接包

本包用于把“界面减字、快速查找与跳转、日期选择、操作闭环”交给新的 Agent 串行完成。

## 使用顺序

1. 把 00_主提示词.md 的完整内容复制给新 Agent。
2. 要求新 Agent 完整阅读本目录全部文件，再开始任何修改。
3. 新 Agent 必须严格按 UX01 → UX02 → UX03 → UX04 → UX05 → UX06 执行。
4. 每个任务都必须先自检、验证、提交一个独立 commit，才能开始下一项。

## 文件说明

- 00_主提示词.md：可直接复制给新 Agent 的完整 prompt。
- 01_项目现状与边界.md：当前代码、生产环境、原生 App 和安全边界。
- 02_任务清单.md：六个任务的范围、验收标准和建议 commit。
- 03_总体验收清单.md：全部完成后逐页检查的清单。

## 重要提醒

- 本包不是原任务清单中的 T54，也不得把这些任务记录成 T54。
- 本轮不允许调用真实 Dify，不允许修改生产数据库，不允许发布 App Store。
- 仓库里现有四份未跟踪的旧交接文档属于用户文件，不能删除、重置、暂存或提交。
- 交接包生成时的基准提交：fde89c4 iOS：新增 Xcode Capacitor App 工程。

## 预计工作量

- 共 6 个串行任务、6 个独立 commit。
- 预计修改或新增约 15～25 个文件，实际以审计结果为准。
- 含浏览器、iOS 和 Android 回归，预计 10～16 小时；保守按 2～3 天安排。
