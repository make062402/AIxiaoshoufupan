### ❌ 已修：R3 开放式提问计数与口径不符（T15-d 引入）

口径原文在 `backend/mock/README.md`：开放式 = **「无法用『是 / 否 / 一个数字』作答」**的问句，
所以「A 还是 B」的选择题一律算封闭。按这把尺子重判四条稿子：

| | 存值 | 实判 | 结论 |
|---|---|---|---|
| R3 | 5/9 | **0/9** | ❌ 九句全是「是不是」「A 还是 B」「有几家」 |
| R4 | 2/8 | 2/8 | ✅ |
| R5 | 1/8 | 1/8 | ✅ |
| R6 | 3/9 | 3/9 | ✅ |

只有 T15-d 写的 R3 错了，T15-c 的 R5/R6 是对的。

**为什么没被任何脚本抓到**：`open_question_count` 属于 P5 那五项语义指标，
脚本只能验分母（问号句数），验不了分子。G 节反推用的也是这个存值，所以存值一错，反推跟着一起错，**自己给自己判卷**。

**修法：改稿而不是改数**。R3 在设计上就是"需求挖掘强"的那一侧（d2=1，与 R4 的 d2=0 成镜像），
写成封闭式本身就是笔误，把数字从 5 改成 0 是掩盖问题。所以把其中 5 句改写成真开放式：

```
 56.5  是只有马桶，还是地漏那边也往上冒？ → 都是哪儿在冒，您给我说说什么情形？
193.4  您这边墙后头是储物间还是过道？     → 您这边墙后头都放着些什么东西？
379.9  是自己做饭多还是店里对付一口多？   → 一天三顿都怎么吃的，您给我说说？
590.3  最在意的是好打理还是好看?          → 这两块,最在意的都是哪几样?
1743.6 有几家在琢磨着要动的?              → 都有谁也在琢磨着要动?
```

保留封闭的 4 句是 31.7 / 122.9 / 218.3 / 1232.2，其中 **1232.2「哑光还是亮面？」是销售岔开话题用的，
封闭是人物需要，不许改成开放**（改了 R3 就变 6/9，且那句的搪塞性质会被削掉，
它同时是 `objection_response_rate = 0.75` 里唯一没接住的那个异议）。

**五句逐字等长**（32/42/41/32/42 字，改写前后一模一样），所以时长折算结果不变、
166 条时间戳一个都没动、总时长仍是 1888.4 秒、所有引文锚点原样有效。
改完 R3 仍是 5/9 = 0.556 ≥ 0.5 达标，D2 5/5，d2=1，总分 2，**镜像关系不受影响**。

> 顺带说明为什么不能图省事改数字：D2 是「5 项中 4 项即得分」，就算开放式那项翻掉，d2 仍是 1、总分仍是 2。
> 但那样 R3 的 D2 会一点余量都不剩，而 R3 注释里本来还有一条抗翻转结论
> 「若 `customer_first_speak_at` 的实现改成『首个客户问句』，这一项翻掉仍是 4/5 → d2 依旧是 1」——
> 两项一起翻就是 3/5，d2 变 0。**改数字会让这条已经写下的抗翻转结论悄悄失效**，改稿则不会。

### P2b 定义（已定，供 T15 执行）

**「档案填了几项」一律按《收敛版需求说明》§3.1 的 8 项口径计，不按数据库列数计。**
