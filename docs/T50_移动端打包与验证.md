# T50 Android 与 iOS PWA 打包说明

## 交付口径

- Web/PWA 默认请求同源 `/api`，适合 T53 由 Nginx 同域转发。
- Android 原生壳必须在构建时填写真实、受信任的 HTTPS 后端。构建脚本会拒绝 HTTP、localhost、空值和示例域名。
- 浏览器只拿到公开后端地址；Dify Key、管理员令牌等密钥仍只在后端保存。
- Android 工程源码进入 Git；`local.properties`、Gradle 缓存、APK/AAB、debug/生产签名材料不进入 Git。本任务没有生成生产签名私钥。
- 2026-08-23 用户已明确同意：T50 完成源码、PWA 安装性和 APK 构建；Android/iPhone 真机安装及 HTTPS 后端联调在 T53 部署可信 HTTPS 后补验。因此本文不把本地构建写成真机通过。

## PWA

`vite-plugin-pwa` 在生产构建中生成：

- `manifest.webmanifest`：中文名称、主题色、背景色、`standalone`、启动路径和 192/512/maskable 图标；
- `sw.js`：预缓存 HTML、CSS、JS、字体和图标形成离线外壳；
- `/api/*` 不进入 precache，也没有 runtime cache；离线时页面壳仍能打开，业务数据明确进入错误态而不是展示过期报告；
- iPhone 所需的 `apple-mobile-web-app-capable`、状态栏样式和 180px touch icon。

T53 有可信 HTTPS 后，在 iPhone Safari 打开站点，点“分享”→“添加到主屏幕”→“添加”。从桌面图标打开后应无 Safari 地址栏，显示绿色应用图标；在线时待办、复盘、客户和报告读取最新后端数据。

## Android 构建

本机已验证工具链：Android Studio 2026.1.3、OpenJDK 21、Android SDK Platform 36、Build Tools 35/36、Platform Tools；应用包名为 `com.aixiaoshou.review`，minSdk 24，target/compileSdk 36。

T53 后把示例文件复制为本机私有配置并填写真实地址：

```bash
cd frontend
cp .env.android.example .env.android.local
# 编辑 .env.android.local，例如 VITE_API_BASE_URL=https://你的域名/api
```

构建 debug APK：

```bash
cd frontend
JAVA_HOME=/opt/homebrew/opt/openjdk@21 \
ANDROID_HOME="$HOME/Library/Android/sdk" \
ANDROID_SDK_ROOT="$HOME/Library/Android/sdk" \
npm run android:apk
```

输出位置：`frontend/android/app/build/outputs/apk/debug/app-debug.apk`（已被 Git 忽略）。这是 debug 安装包，仅供真机验收，不用于应用商店发布。

T53 真机安装后依次验证：桌面图标和名称正确；点击后全屏且无浏览器地址栏；网络请求只访问填写的 HTTPS 后端；打开待办、复盘、我的客户和一条稳定报告 URL 均能读取最新数据。可用下列命令安装到已授权 USB 调试设备：

```bash
"$HOME/Library/Android/sdk/platform-tools/adb" install -r frontend/android/app/build/outputs/apk/debug/app-debug.apk
```
