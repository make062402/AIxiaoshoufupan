## 本次目标环境

- 云厂商：阿里云 ECS，华南 3（广州）
- 公网 IP：`8.134.128.117`
- 系统：Ubuntu 22.04.5 LTS（64 位）
- SSH 用户：`root`，通过阿里云 Workbench 免密连接
- 计费：按量付费
- 本任务安装：Node.js 22、Nginx、PM2
- 本任务不做：宝塔配置、UFW 规则调整、业务部署、PM2 开机自启、HTTPS

不要把服务器密码、SSH 私钥、证书私钥或业务环境文件写进仓库。项目脚本不会读取这些内容。

## 安装与复查

将仓库放到 Ubuntu 22.04 服务器后，以 `root` 执行：

```bash
chmod +x ops/install-server-env.sh ops/check-server-env.sh
./ops/install-server-env.sh
```

脚本会安装固定主版本 Node.js 22、Ubuntu 仓库中的 Nginx 和 `pm2@7.0.3`，随后自动运行检查。重复执行是安全的；已经满足版本要求的软件不会被无条件重装。

只复查、不安装：

```bash
./ops/check-server-env.sh
```

检查通过时应看到：

- `Node.js: v22...`，并显示 Node.js 主版本通过；
- `npm` 有版本号；
- `nginx version` 有版本号，配置语法正确；
- Nginx 为 `active`、`enabled`，TCP 80 正在监听；
- 服务器本机访问 `http://127.0.0.1/` 成功；
- PM2 有版本号，状态命令可执行；
- 最后一行是“环境检查通过”。

也可以逐条人工核对：

```bash
node -v
npm -v
nginx -v
nginx -t
systemctl is-active nginx
systemctl is-enabled nginx
pm2 -v
pm2 status
curl -I http://127.0.0.1/
ss -lntp
```

## 公网访问验收

Nginx 在服务器内成功并不代表公网已经放行。浏览器访问：

```text
http://8.134.128.117/
```

应看到 Nginx 默认欢迎页。若服务器本机返回 `200 OK`，但公网打不开，请依次检查：

1. 阿里云实例绑定的安全组是否有入方向 `TCP 80` 规则；
2. 规则来源是否符合预期（演示环境可临时使用 `0.0.0.0/0`，生产环境应按实际需要收窄）；
3. UFW 是否允许 80；
4. `ss -lntp` 是否显示 Nginx 监听 `0.0.0.0:80` 或 `[::]:80`；
5. `/var/log/nginx/access.log` 是否出现公网请求。

开放 `0.0.0.0/0:80` 会让所有互联网用户访问 HTTP 服务。修改云安全组前必须明确确认影响；本仓库脚本不会自动修改 UFW 或阿里云安全组。
